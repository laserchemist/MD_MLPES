MD_MLPES

Machine-Learning Potential Energy Surfaces for Criegee Intermediate Dynamics & IR Spectroscopy

Jonathan M. Smith  ·  Temple University  ·  2025–2026

About this project

This repository develops ML-PES pipelines for Criegee intermediates: PSI4 quantum chemistry → Coulomb-matrix descriptor → Kernel Ridge Regression → ML-MD → IR spectra. Multi-state CASSCF/NEVPT2 corrections are applied via normal-mode coordinate delta-ML. The MACE equivariant neural network backend is the current preferred engine for vibrational spectra.
